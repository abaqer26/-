# سيرفر تحليل صور الأكل

هذا سيرفر صغير يستقبل صورة أكل من الداشبورد، يحللها فعليًا بالذكاء الاصطناعي (Claude vision)، ويرجع تقدير غذائي حقيقي (سعرات، كارب، بروتين، دهون، سكر).

## ليش أحتاج سيرفر منفصل؟

مفتاح الـ API لازم يضل سري. ما ينحط أبدًا داخل ملف HTML يوزّع للناس، لأن أي شخص يقدر يفتح كود الصفحة ويسرقه. السيرفر هذا يحفظ المفتاح عنده فقط، والداشبورد يتواصل معه بدون ما يشوف المفتاح.

## التشغيل محليًا (للتجربة)

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="مفتاحك_هنا"
uvicorn server:app --reload --port 8000
```

جرّبه:
```bash
curl http://localhost:8000/health
```

## الحصول على مفتاح API

من https://console.anthropic.com — تحتاج تسجيل وربط وسيلة دفع (التسعير حسب الاستخدام، كل صورة تكلفة بسيطة جدًا مع موديل Haiku).

## النشر الفعلي (عشان يشتغل لأي أحد يفتح الداشبورد)

انشره على أي خدمة تدعم Python، مثل Render أو Railway أو Fly.io (كلها فيها خطة مجانية أو رخيصة تكفي البداية):

1. ارفع هذا المجلد لحساب GitHub خاص فيك.
2. في إعدادات الخدمة اللي تختارها: اربط الرِبو، وحط متغير بيئة `ANTHROPIC_API_KEY` بمفتاحك (لا تكتبه داخل الكود أبدًا).
3. أمر التشغيل: `uvicorn server:app --host 0.0.0.0 --port $PORT`
4. بعد ما ينشر، بتاخذ رابط مثل `https://your-app.onrender.com`.
5. افتح الداشبورد (health-dashboard-concept.html)، روح لقسم "مسح منتج بالكاميرا" → "إعدادات سيرفر التحليل"، والصق الرابط واضغط حفظ.

## ملاحظة مهمة

هذا تحليل بالذكاء الاصطناعي — تقدير تقريبي مو نتيجة مخبرية دقيقة 100%. خله واضح للمستخدمين النهائيين (الليبل بالداشبورد يوضح هذا).
